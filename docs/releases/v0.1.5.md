**BNC Docs 0.1.5 is a pre-release.** It is an open-source word processor with real paginated pages, a Word-style ribbon, **`.docx` import/export**, its own `.bncdoc` format, and Nextcloud support. It runs on Windows, macOS and Linux with the same code.

Pre-release means: it works and has been tested, but it has not had wide use yet, and the installers are **not code-signed**, so your operating system will show a warning the first time (see below). Please report problems in Issues.

## Install

**Windows:** run the installer, or just run the portable exe (no installation, it keeps its settings in your user profile). Because it is not signed, Windows SmartScreen may say "Windows protected your PC": choose **More info** then **Run anyway**.

**macOS:** unzip and drag **BNC Docs** into **Applications**. The first time, right-click it and choose **Open** then **Open** again (on macOS 15: System Settings > Privacy & Security > **Open Anyway**), or run `xattr -dr com.apple.quarantine "/Applications/BNC Docs.app"`. The app is ad-hoc signed but not notarized.

**Ubuntu / Debian:** `sudo apt install ./BNC-Docs-0.1.5-linux-amd64.deb` (uninstall with `sudo apt remove bnc-docs`).
**AppImage:** `chmod +x BNC-Docs-0.1.5-linux-x86_64.AppImage` then run it.

## What is new in 0.1.5

- **Spell check and punctuation check as you type.** Misspelt words get a red wavy line, punctuation slips a blue one. Right-click for corrections, or press **F7** for a pane that goes through every problem (Change, Ignore Once, Ignore All, Add to Dictionary).
- Works **offline** and the same on Windows, macOS and Linux: Hunspell dictionaries for **English (US / UK / Australia)** are built in. The status bar shows the language (click to change) and the number of problems.
- Punctuation checks: extra spaces, space before a comma or full stop, missing space after one, doubled punctuation, repeated words, a sentence starting with a small letter, a lower-case "i", "a" / "an", unclosed brackets and quotes. These are simple rules, not a full grammar checker.
- **AutoCorrect** for about 200 common typos (teh, recieve, definately, dont ...) and "i" to "I"; one Ctrl+Z restores what you typed.
- A custom dictionary (Review > Language > Custom dictionary) and switches for spelling, punctuation and AutoCorrect on the Review tab.
- Fixes: Word documents with non-breaking hyphens now import correctly, and the "..." in command search labels shows properly.
## What is in it

- Paginated pages, ribbon, tables, pictures, lists, styles, find & replace, headers/footers, spell check, dark/light theme
- `.docx` (Word), `.bncdoc`, Markdown, HTML, text and RTF; PDF export and printing
- Nextcloud: sign in through your browser (no password typed into the app), open/save, conflict detection, AutoSave
- App colour styles (plugins), see [bnc-plugins](https://github.com/PigeonBoi69/bnc-plugins)

## Known limitations

- No comments, track changes, footnotes, equations or columns yet; tables are not split across pages.
- Word documents can paginate slightly differently than in Word (fonts such as Aptos are substituted when they are not installed).
- Tested: Windows (installed and run), Linux (clean Ubuntu 24.04 container), macOS (package contents checked, but **not run on a real Mac yet**).
- Nextcloud has been tested against a mock server only.
- Proofing is English only (US, UK, Australia) and rule based: it does not check grammar such as there/their or verb agreement.
